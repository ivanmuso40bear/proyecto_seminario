# Sistema WEB de Bitácoras / Visitas - Universidad INSUCO

Este es un sistema web digital desarrollado como proyecto escolar para la carrera de **Ingeniería en Sistemas Computacionales** en la Universidad INSUCO. El objetivo principal es transformar una bitácora tradicional en papel en una plataforma web segura y digital.

##  Funcionalidades Principales
* **Control de Acceso:** Login seguro y control de accesos mediante sesiones en PHP.
* **Registro Digital:** Captura de datos completa (Nombre, Campus, Fecha, Horas, Objetivo, Actividades, Resultados y Notas).
* **Firma Digital:** Área de firmado digital integrada con Canvas HTML5 (compatible con Mouse, TouchPad y pantallas táctiles).
* **CRUD Completo:** Altas, Consultas, Modificaciones y Bajas de registros de bitácoras.
* **Reportes en PDF:** Generación de archivos PDF que respetan el diseño institucional para impresión y respaldos.

##  Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap (Plantilla oficial institucional).
* **Backend:** PHP.
* **Base de Datos:** MySQL.
* **Librerías especiales:** Signature Pad (para firmas) y exportación a PDF.

##  Distribución del Trabajo (Equipo 4)
* **Integrante 1:** Líder y Documentación (Planeación, Cronograma, Manual Técnico e Integración).
* **Integrante 2:** Diseño Frontend (Adaptación de la plantilla oficial e Interfaz responsiva).
* **Integrante 3:** Backend PHP (Login, Sistema CRUD, Control de Sesiones y Validaciones).
* **Integrante 4:** Base de Datos (Estructura en MySQL, Creación de Tablas y Consultas SQL).
* **Integrante 5:** Firma Digital y PDF (Área de Canvas HTML5, Signature Pad y Exportación de Evidencias).
* **Integrante 6:** Por asignar.
